**Proyecto**  
Aplicación web desarrollada para gestionar información de usuarios y sus datos de forma sencilla.

**Comandos principales**  
\`\`\`bash  
npm install  
npm run dev  
npm run build  
npm test  
\`\`\`

**Reglas de estilo de código**  
\- Usar nombres de variables y funciones descriptivos.  
\- Variables y funciones en \`camelCase\`.  
\- Clases y componentes en \`PascalCase\`.  
\- Mantener funciones cortas y reutilizables.  
\- Comentar únicamente cuando sea necesario.  
\- Mantener una indentación de 2 o 4 espacios de forma consistente.

**Qué puede hacer el agente**  
\- Crear nuevos archivos y componentes.  
\- Corregir errores del código.  
\- Refactorizar funciones para mejorar la legibilidad.  
\- Agregar comentarios cuando sean útiles.  
\- Proponer mejoras de rendimiento.  
\- Escribir pruebas unitarias.

**Qué NO debe hacer sin permiso**  
\- Eliminar archivos.  
\- Cambiar dependencias del proyecto.  
\- Modificar la base de datos.  
\- Cambiar configuraciones importantes.  
\- Subir cambios a Git o hacer commits.  
\- Exponer información sensible o credenciales.
